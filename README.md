## Skills I'm building here

- GUI development with **Pygame**, **Tkinter**, **PyQt**
- Object-oriented design and clean project structure
- Procedural generation (sprites, audio, backgrounds — no asset files)
- Physics simulation and game-feel (easing, spring systems, particles)
- Automation and scripting
- Working with popular libraries: `numpy`, `pygame`, `requests`, and more

## Getting started with any project

Each project has its own folder with a dedicated README. But the general setup is always:

```bash
# Clone the repo
git clone https://github.com/yourusername/python-playground.git
cd python-playground

# Go into any project
cd dragon_pet

# Install its dependencies
pip install -r requirements.txt

# Run it
python main.py
```
